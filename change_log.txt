- 优化含子模块的 git 仓库打开速度：子模块路径改为直接解析 .gitmodules，不再执行较慢的 git submodule status
- git 提交记录改为按需加载变更文件：打开日志只查询提交元数据，点击某条提交时再获取该提交的文件列表（按打开日志时的目录/文件过滤，切换目录不会串用其它目录的文件缓存）
